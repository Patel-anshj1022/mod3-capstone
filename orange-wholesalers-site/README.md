OrangeLink Wholesalers — Static Website
======================================

An animated, orange-themed wholesale company website with multiple pages and subtle GSAP enhancements.

Preview
-------

Open `index.html` directly in your browser, or serve locally for best results:

```bash
cd /workspace/orange-wholesalers-site && python3 -m http.server 5173
# then visit http://localhost:5173
```

Structure
---------

- `index.html`: Landing page with hero, features, categories, testimonials
- `about.html`: Company overview and leadership
- `products.html`: Category showcase with cards
- `contact.html`: Quote request form (demo handler)
- `assets/css/styles.css`: Theme and animations
- `assets/js/main.js`: Interactivity and GSAP effects

Notes
-----

- External images are hotlinked from Unsplash and avatars from `i.pravatar.cc`.
- GSAP is loaded via CDN and used for non-blocking reveal animations.
- The contact form is a demo (no backend). Replace the handler in `assets/js/main.js` to POST to your API.
